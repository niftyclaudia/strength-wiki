# strength-wiki

Obsidian vault for strength training during a marathon block (race Mar 21, 2027; long run every Saturday). Modeled on finessevanes/training-wiki.

- Log workouts into the current phase file under `Training/phases/` (see the status column in `Training/index.md`). Use the same table format as existing log entries. Weights are in lb.
- At the end of a phase: write the Phase Summary, copy working weights to `Training/benchmarks.md`, then create the next phase file.
- Personal patterns go to `Training/insights.md`. General knowledge from sources goes to `Wiki/`. Raw sources go to `Clippings/`.
- Use `[[wikilinks]]` for cross-references.
- Phase 0 is 3 days (Tue/Thu/Sun). From Phase 1 on: 2 full-body days (Tue lower-heavy + Thu or Sun upper-heavy).
- Scheduling rule: heavy lower on Tuesday only; nothing loaded for legs the day before the Saturday long run.
- Sessions are 30 min max. Effort ramps in 4-week waves: week 1 RPE 5–6, weeks 2–3 main barbell lifts RPE 7 (accessories stay RPE 5–6), week 4 deload. Never program past RPE 7.
- Plyo/balance block after the warm-up: full on Tue (~60 contacts to start), light on Thu, none on Sun (day after long run). Progression is in `Wiki/plyometrics-and-balance.md`.
- Primary success metric: hip thrust 3x10 working weight (track in `Training/benchmarks.md`).
