# strength-wiki

A personal Obsidian vault for strength training during marathon training (race: **March 21, 2027**).

## Structure

- **`Training/`** — what I actually did: phase programs, weekly lift logs, benchmarks, insights
- **`Wiki/`** — reference notes: strength for runners, exercise cues
- **`Clippings/`** — saved articles, podcasts and research excerpts that feed the Wiki
- **`.obsidian/`** — vault configuration

Running data lives in `marathon-hq`. This vault is only for lifting and how lifting interacts with running.

## Usage

Open the repo as a vault in [Obsidian](https://obsidian.md). All notes use standard Markdown with `[[wikilinks]]` for cross-references.

Start at [[Training/index]].
