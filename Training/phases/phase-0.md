# Phase 0: Intro Week

**Dates:** September 28 – October 4, 2026 (1 week, the week before marathon training starts)
**Goal:** Learn the program, find starting weights, and see how lifting feels around the Saturday long run
**Structure:** 3 days: Tue lower, Thu upper, Sun upper-biased full body
**Effort:** RPE 6–7 on everything (3–4 reps left in the tank). The point is to find working weights, not to test max effort.

> **Finding your weight:** Start light. If the last rep of a set felt like you had 5+ reps left, go up next set. If you had fewer than 3 left, stay or drop. Write down the weight that felt like RPE 7. That becomes your Phase 1 starting weight.

## Program

### Day 1 — Tuesday Sep 29: Lower (squat + hinge)
Warm-up (8 min): 5 min easy cardio → band lateral walk 2x10 each way → glute bridge 1x15 → bodyweight squat 1x10 → empty-bar squats 2x5

| Exercise | Sets x Reps | Rest |

| D2. Dead bug | 3x8/side | 60s |

### Day 2 — Thursday Oct 1: Upper + light single-leg
Warm-up (6 min): band pull-apart 1x15 → band dislocates 1x10 → push-up 1x5 → empty-bar press 2x5

| Exercise | Sets x Reps | Rest |
|---|---|---|

*Two days before the long run: keep the single-leg RDL light. It's for balance, not load.*

### Day 3 — Sunday Oct 4: Upper-biased full body + core (day after long run)
Warm-up (6 min): easy walk or bike → cat-cow 1x8 → glute bridge 1x10 → band pull-apart 1x15

| Exercise | Sets x Reps | Rest |
|---|---|---|
| A1. Barbell floor press (in the rack) | 3x8 | 2 min |
| B1. Barbell glute bridge | 3x10 | 90s |
| C1. Band lat pulldown (band anchored high on rack) *or* chin-up if rack has a bar | 3x10 | 90s |

| D1. Band Pallof press | 3x10/side | 45s |
| D2. Kettlebell suitcase carry | 3x30 m/side | 60s |

Cool-down (10 min): couch stretch, 90/90 hips, calf stretch against wall, child's pose

*If legs are cooked from Saturday, drop the glute bridge to 2 sets or skip it. Upper body and core are the priority today.*

## Rules Around Running

1. **Heavy legs stay far from the long run.** Tuesday is the heavy lower day. Nothing heavy for legs Thu–Sat.
2. **Same-day run + lift:** run first, lift later. Space them 6+ hours apart if possible.
3. **Stop 2–3 reps short of failure.** Soreness that changes your running stride is too much.
4. **If a run and a lift conflict, the run wins** (except the Tuesday squat day, which is worth protecting).

## Progression (for Phase 1)

When you hit the top of the rep range on all sets at RPE ≤ 7, add weight next session:
- Squat / RDL / glute bridge: +5–10 lb
- Press / row / floor press: +2.5–5 lb
- Kettlebell moves: add reps first, then size up the bell
