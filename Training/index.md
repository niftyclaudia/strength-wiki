# Training Wiki

Strength training alongside marathon training. What I actually lifted and how my body (and my running) responded.

For reference knowledge, see [[Wiki/index|Strength for Runners Wiki]].

**Race:** Sunday, March 21, 2027
**Goal:** Keep and build muscle through the marathon block without hurting the running
**Equipment:** Squat rack, barbell + plates, kettlebell, bands
**Weekly anchor:** Long run every **Saturday**

---

## Training Phases

Phases follow the marathon block: lift the most when mileage is low, then taper strength down as mileage peaks.

| Phase | Dates | Marathon block | Lift days/wk | Focus | Status |
|---|---|---|---|---|---|
| [[phases/phase-0]] | Sep 28 – Oct 4, 2026 | Pre-block | 3 | Intro week: learn the program, set starting weights | In progress |
| phase-1 | Oct 5 – Nov 29, 2026 (8 wks) | Base | 2 | Build: hypertrophy + strength, highest lifting priority | Planned |
| phase-2 | Nov 30, 2026 – Jan 24, 2027 (8 wks) | Build | 2 | Strength: heavier, fewer reps, less volume | Planned |
| phase-3 | Jan 25 – Mar 7, 2027 (6 wks) | Peak mileage | 2 (shorter) | Maintain: keep intensity, cut sets | Planned |
| phase-4 | Mar 8 – Mar 21, 2027 (2 wks) | Taper + race | 1 → 0 | Stay sharp: light session(s), nothing heavy race week | Planned |

Create each phase file when you get to it. Deload weeks should line up with the running plan's cutback weeks.

## Weekly Shape

**This week (Phase 0), 3 days:**

| Day | Lifting |
|---|---|
| Tue | **Lower (heavy)**: 4 days before the long run, so legs recover |
| Thu | **Upper + light single-leg** |
| Sat | **Long run** |
| Sun | **Upper-biased full body + core**: legs are tired from Saturday |

**From Phase 1 onward, 2 days:** both sessions become full body so nothing gets skipped.

| Day | Lifting |
|---|---|
| Tue | **Full body A, lower-heavy**: squat + RDL heavy, plus one push and one pull |
| Thu *or* Sun | **Full body B, upper-heavy**: press + row heavy, light single-leg, calves, core |
| Sat | **Long run** |

*Pick Thu or Sun for Day B once the running plan is set. Thursday works if it's an easy run day. Sunday works if Thursday is a quality run (tempo or intervals).*

## How This Wiki Works

Each phase file has the program, a weekly log, and a short phase summary. [[benchmarks]] tracks lifts across phases so trends are easy to see. [[insights]] captures patterns, like "heavy squats on Tuesday make my Thursday run feel flat", and links back to the [[Wiki/index|reference wiki]] when relevant.
